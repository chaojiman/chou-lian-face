# 抽象丑脸生成 · 微信小程序

一个 **100% 纯前端、零依赖、零成本** 的微信小程序。
上传一张照片，它会提取你的配色与脸型比例，然后长出一张抽象又丑萌的脸。

参考实现：[Rockyzsu/ugly-avatar](https://github.com/Rockyzsu/ugly-avatar)（Vue + SVG，原版没有上传照片功能）

---

## 一、它做了什么

| 能力 | 说明 |
|---|---|
| 随机生成 | 点「重新生成」得到一张全新的、无法预测的脸 |
| 上传照片 | 从照片中提取 **肤色 / 发色 / 背景色 / 脸型比例**，用这四项驱动生成 |
| 保存相册 | 导出 PNG 到手机相册 |

所有计算都在手机本地完成：**不上传图片、不调用任何接口、不需要后端、不需要服务器**。

---

## 二、技术方案

### 1. 从 SVG 移植到 Canvas 2D

原版用的是内联 SVG + `feTurbulence` / `feDisplacementMap` 滤镜。
小程序不支持内联 SVG，所以做了两件事：

- 把 SVG 的 `polyline` / `path` / `circle` 全部翻译成 Canvas 2D 路径指令；
- 用 **低频正弦抖动（wobble）** 替代 `feDisplacementMap`，再叠一道错位描边，
  复现那种歪歪扭扭的手绘线条。闭合图形（脸廓）用整数倍频率，保证接缝处不裂开。

坐标系与 SVG 的 `viewBox="-100 -100 200 200"` 保持一致，
所以四个几何算法模块可以**原样复用**，一行数值都不用改。

### 2. 四个几何模块（纯数学，无依赖）

| 文件 | 职责 | 原理 |
|---|---|---|
| `utils/face_shape.js` | 脸型轮廓 | 隐式曲线 `x²/a²·(1+ky) + y²/b² = 1` 生成两条蛋形曲线，按 1/4 相位差混合 |
| `utils/eye_shape.js` | 眼睛 | 上下眼睑各一条三次贝塞尔，控制点随机偏移；再与"收敛辅助曲线"二次混合 |
| `utils/hair_lines.js` | 头发 | 从脸廓随机取点串成高维贝塞尔曲线，四种生成器随机叠加 |
| `utils/mouth_shape.js` | 嘴巴 | 三种嘴型（大笑 / 歪嘴 / 厚唇）随机三选一 |

> 性能优化：原版在贝塞尔求值的 `t` 循环内部反复计算阶乘与二项式系数，
> 单条曲线就要几十万次运算。这里改成**一次预计算 + 复用**，并用阶乘缓存表，
> 300 次连续生成耗时从数秒降到 1.8 秒（平均 6ms/张）。

### 3. 照片配色分析 `utils/palette.js`

上传流程：`chooseMedia` → 绘到 canvas → `getImageData` 读像素 → 分析 → 生成。

提取四项参数：

- **肤色** —— 画面中央偏下区域的"暖色低饱和"像素
- **发色** —— 顶部区域的暗色像素，且必须与肤色拉开距离
- **背景色** —— 画面四周环形区域的颜色
- **脸型比例** —— 用提取到的肤色反查全图，取包围盒长宽比

其中踩了三个坑，也是这个模块最有价值的部分：

**① 位置先验 + 两遍扫描。**
棕发和浅肤色的 RGB 空间高度重叠，单靠颜色根本分不开
（`rgb(92,62,40)` 的棕发完全落在肤色判定区间内）。
所以第一遍只在中下部找肤色，第二遍拿肤色当参照去找头发。

**② 用「颜色直方图取众数」而不是「取平均」。**
背景角落里混进来的几个像素就能把平均值拉偏 ——
实测一张深肤色照片，因为近白色墙壁被误判成皮肤，肤色被从 `124,84,62` 洗成了 `165,130,109`。
换成直方图众数后误差从 Δ77 降到 Δ31。

**③ 按「合并后簇」的规模选众数，而不是按单桶计数。**
同一块纯色会因为量化和噪点被切进好几个相邻的桶
（白色背景可能同时落在 8 个桶里），单桶最大值那个颜色
很可能是另一块面积更小但更集中的区域（比如头发）。
所以先取计数最高的 16 个桶当种子，再算每颗种子合并邻域后的**簇总规模**，最大的才是主色。

另外还有一道兜底：如果提取出的背景色和肤色太接近，脸会融进背景看不见，
此时会强制把背景压暗或提亮来拉开对比度。

### 4. 尺寸与清晰度

Canvas 2D 的 `width`/`height` 是**设备像素**，必须乘 `dpr` 才不会糊：

```js
canvas.width  = item.width  * dpr;
canvas.height = item.height * dpr;
```

绘制时用 `setTransform` 把世界坐标 `200×200` 映射到画布，
线宽也写在世界坐标里，这样不同机型上视觉粗细完全一致。

## 四、本地调试

直接用微信开发者工具打开本目录即可（`project.config.json` 里预填的是游客 AppID）。

如果想脱离小程序调试几何算法，可以用工作区里的 Node 脚本：

```bash
node tools/preview-face.js 6     # 把生成结果导出为 SVG
node tools/test-palette.js       # 测试取色模块准确度
node tools/stress.js             # 300 次生成的稳定性与性能压测
```

这些脚本在 `chou-lian-face/` 目录**之外**，不会被上传到小程序包里。

## 五、需要真机验证的点

| 项目 | 说明 |
|---|---|
| `getImageData` | 小程序 2D canvas 的像素读取。代码里已做 try/catch 降级 —— 万一机型不支持，会退回随机配色并给出提示，不会崩 |
| 相册权限 | 首次保存会弹出授权；被拒绝后可「去设置」重新开启 |
| 低端机性能 | 已把头发线条数上限压到 300 条，实测平均 6ms/张（桌面 Node），手机上预计 30–80ms |
